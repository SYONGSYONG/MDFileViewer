# Markdown 문법 도움말

문법마다 **작성 예시**(원문)와 **결과**(렌더링)를 함께 보여 줍니다. 왼쪽 목차를 누르면 그 문법으로 갑니다.

## 1. 제목

작성 예시:

```markdown
# 제목 1
## 제목 2
### 제목 3
#### 제목 4
##### 제목 5
###### 제목 6
```

결과:

<p><strong>제목 1</strong>부터 <strong>제목 6</strong>까지 글자 크기가 단계별로 작아집니다. <code>#</code> 뒤에는 공백을 한 칸 둡니다.</p>

## 2. 문단과 줄 바꿈

작성 예시:

```markdown
첫 번째 문단입니다.

빈 줄로 문단을 나눕니다.
줄 끝에 공백 두 칸을 두면··
줄만 바뀝니다. <br>도 줄을 바꿉니다.
```

(`··`는 공백 두 칸을 보이게 한 표시입니다.)

결과:

첫 번째 문단입니다.

빈 줄로 문단을 나눕니다.
줄 끝에 공백 두 칸을 두면  
줄만 바뀝니다. <br>도 줄을 바꿉니다.

## 3. 강조

작성 예시:

```markdown
**굵게**, *기울임*, ***굵은 기울임***, ~~취소선~~
```

결과:

**굵게**, *기울임*, ***굵은 기울임***, ~~취소선~~

## 4. 목록

작성 예시:

```markdown
- 순서 없는 항목
- 다른 항목
  - 들여 쓴 하위 항목

1. 첫째
2. 둘째
   1. 하위 순서
```

결과:

- 순서 없는 항목
- 다른 항목
  - 들여 쓴 하위 항목

1. 첫째
2. 둘째
   1. 하위 순서

## 5. 작업 목록

작성 예시:

```markdown
- [ ] 할 일
- [x] 끝낸 일
```

결과:

- [ ] 할 일
- [x] 끝낸 일

## 6. 링크

작성 예시:

```markdown
[인라인 링크](https://example.com)
[참조형 링크][예시]
<https://example.com>
[문서 안 앵커](#1-제목)
[다른 md 파일](./README.md)

[예시]: https://example.com
```

결과:

[인라인 링크](https://example.com)
[참조형 링크][예시]
<https://example.com>
[문서 안 앵커](#1-제목)

[예시]: https://example.com

- 외부 링크는 기본 브라우저로 엽니다.
- 다른 md 파일 링크는 이 앱의 탭으로 엽니다. `#앵커`를 붙이면 그 위치로 갑니다.
- 앵커 이름은 제목 글자를 소문자로 바꾸고 공백을 `-`로 바꾼 것입니다.

## 7. 이미지

작성 예시:

```markdown
![대체 텍스트](images/그림.png)
![위 폴더의 그림](../assets/logo.png "제목")
```

결과: 문서 파일이 있는 폴더를 기준으로 그림을 찾아 보여 줍니다. 그림을 찾지 못하면 대체 텍스트가 보입니다.

## 8. 인용

작성 예시:

```markdown

>
> > 중첩 인용입니다.
```

결과:

>
> > 중첩 인용입니다.

## 9. 코드

작성 예시:

~~~markdown
문장 안의 `인라인 코드`

```csharp
var message = "언어를 지정한 코드 블록";
```
~~~

결과:

문장 안의 `인라인 코드`

```csharp
var message = "언어를 지정한 코드 블록";
```

결과:

| 왼쪽 | 가운데 | 오른쪽 |
|:-----|:------:|-------:|
| 가   | 나     | 다     |
| 1    | 2      | 3      |

## 12. 각주

작성 예시:

```markdown
각주가 붙은 문장입니다.[^1]

[^1]: 각주 내용은 문서 끝에 모입니다.
```

결과:

각주가 붙은 문장입니다.[^1]

[^1]: 각주 내용은 문서 끝에 모입니다.

## 13. 이스케이프

작성 예시:

```markdown
\*별표 그대로\*, \# 샵 그대로, \[대괄호\]
```

결과:

\*별표 그대로\*, \# 샵 그대로, \[대괄호\]

## 14. HTML과 이 앱의 제한

작성 예시:

```markdown
<kbd>Ctrl</kbd>+<kbd>S</kbd> 처럼 HTML 태그를 섞어 쓸 수 있습니다.
<script>alert('실행되지 않습니다')</script>
```

결과:

<kbd>Ctrl</kbd>+<kbd>S</kbd> 처럼 HTML 태그를 섞어 쓸 수 있습니다.

- 이 앱은 문서 안의 **스크립트를 실행하지 않습니다**(`<script>`, `onclick` 같은 속성 모두). 문서를 안전하게 보기 위한 제한입니다.

## 15. YAML front matter

작성 예시:

```markdown
---
title: 문서 제목
tags: [안내, 예시]
---

# 본문 시작
```

결과: 문서 맨 앞의 `---` 사이 내용(front matter)은 본문에 보이지 않습니다.

| 단축키 | 동작 |
|--------|------|
| `Ctrl+E` | 보기 ↔ 편집 전환 |
| `Ctrl+S` | 저장 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 확대 / 축소 / 100% |
| `Ctrl+마우스 휠` | 확대·축소 |
| `Ctrl+B` | 탐색 패널 접기/펴기 (편집기 안에서는 굵게) |
| `Ctrl+Shift+B` | 목차 패널 여닫기 (보기 모드) |
| `Ctrl+O` | 폴더 열기 |
| `F5` | 새로고침 |
| `F2` / `Delete` | 트리에서 고른 md 파일 이름 바꾸기 / 삭제 |
| `F1` | 도움말 |
| `Ctrl+F` | 문서 안 찾기 (보기 모드) · 편집기 안 찾기 (편집 모드) |
| `Ctrl+H` | 편집기에서 찾아 바꾸기 |
| `Ctrl+B` · `Ctrl+I` · `Ctrl+Shift+X` | 편집기: 굵게 · 기울임 · 취소선 |
| `` Ctrl+` `` · `Ctrl+K` | 편집기: 코드 · 링크 |
| `Ctrl+Alt+1` ~ `Ctrl+Alt+6` | 편집기: 제목 1~6단계 |
| `Ctrl+Shift+8` · `7` · `9` · `.` | 편집기: 글머리 목록 · 번호 목록 · 작업 목록 · 인용 |
| `Ctrl+P` | 인쇄 |
| `Enter` / `Shift+Enter` · `F3` / `Shift+F3` | 다음 / 이전 찾은 곳 (찾기 줄이 열려 있을 때) |
| `Esc` | 찾기 줄 닫기 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |
| `Ctrl+W` | 활성 탭 닫기 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 다음 / 이전 탭 |
