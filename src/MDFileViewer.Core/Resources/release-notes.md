# 릴리즈 노트

MDFileViewer의 버전별 변경 내용입니다. 최신 버전이 위에 있습니다.

## 1.3.1

### 고친 문제

- 편집 모드에서 한 번만 고친 문서가 저장되지 않던 문제를 고쳤습니다. 굵게 버튼을 한 번 누르거나 **모두 바꾸기**를 한 번 한 뒤에는 제목에 변경 표시(`*`)가 나오지 않았고, 저장해도 파일이 그대로였습니다. 한 번 더 고치면 표시가 나왔습니다.

### 바뀐 점

- 프로그램을 켠 뒤 처음 여는 문서가 더 빨리 보입니다. 폴더를 연 채로 켜면, 문서를 고르기 전에 표시 준비를 미리 해 둡니다.

## 1.3.0

### 새 기능

- 편집기에 그림을 붙입니다. 화면 캡처나 복사한 그림을 편집 모드에서 `Ctrl+V`로 붙이면, 문서가 있는 폴더의 `images` 폴더에 PNG 파일로 저장하고 그 자리에 그림 링크를 넣습니다.
- 탐색기에서 복사한 그림 파일도 `Ctrl+V`로 붙일 수 있고, 그림 파일을 편집기에 끌어다 놓으면 놓은 자리에 들어갑니다. 한 번에 20개까지 넣습니다.
- 붙인 그림의 이름은 `문서이름-날짜-시각.png`이고, 가져온 파일은 원래 이름을 씁니다. 같은 이름이 있으면 덮어쓰지 않고 `-2`, `-3`을 붙입니다.
- 이미 문서 폴더 안에 있는 그림 파일은 복사하지 않고 그 자리를 가리키는 링크만 넣습니다.

### 고친 문제

- 창을 닫은 뒤에도 프로그램이 보이지 않게 남아 있을 수 있던 문제를 고쳤습니다. 이렇게 남으면 다음 설치 때 "MDFileViewer가 실행 중"이라고 나왔습니다.

### 바뀐 점

- 문제를 가려내기 쉽게 로그에 버전과 시작·종료 기록을 남깁니다.

## 1.2.0

### 새 기능

- 트리에서 문서를 만들고, 이름을 바꾸고, 지웁니다. 폴더를 우클릭해 **새 문서…**, md 파일을 우클릭해 **이름 바꾸기…**(`F2`)나 **삭제**(`Delete`)를 고릅니다.
- 지운 문서는 휴지통으로 갑니다. 네트워크 드라이브나 USB처럼 휴지통이 없는 곳에서는 완전히 지워진다고 알린 뒤 묻습니다.
- 편집기에서 단축키로 서식을 넣습니다. 굵게(`Ctrl+B`), 기울임(`Ctrl+I`), 취소선(`Ctrl+Shift+X`), 코드(`` Ctrl+` ``), 링크(`Ctrl+K`), 제목(`Ctrl+Alt+1`~`6`), 글머리 목록(`Ctrl+Shift+8`), 번호 목록(`Ctrl+Shift+7`), 작업 목록(`Ctrl+Shift+9`), 인용(`Ctrl+Shift+.`). 같은 키를 다시 누르면 서식이 벗겨집니다.
- 편집기 위에 서식 도구 모음이 생겼습니다. 제목 단계는 드롭다운에서 한 번에 고릅니다.
- 편집기에서 찾은 곳을 모두 형광펜처럼 칠합니다. 오른쪽 미리보기에도 같은 말이 칠해집니다.
- 편집기에서 찾은 말을 바꿉니다(`Ctrl+H`). 하나씩 바꾸거나 모두 바꿀 수 있고, 대소문자를 구분해 찾을 수 있습니다.
- 설치 화면에 **탐색기 우클릭 메뉴에 "MDFileViewer로 열기" 추가** 항목이 생겼습니다. 기본으로 켜져 있어, 설치하면 탐색기 메뉴가 바로 등록됩니다.

### 바뀐 점

- 편집기에 포커스가 있을 때 `Ctrl+B`는 굵게입니다. 탐색 패널은 툴바 버튼으로, 또는 편집기 밖에서 `Ctrl+B`로 접고 폅니다.
- 편집기의 찾기(`Ctrl+F`)가 편집기 위의 찾기·바꾸기 줄로 바뀌었습니다.
- 프로그램을 켠 뒤 첫 문서가 더 빨리 열립니다. 폴더 트리를 펼치는 것을 기다리지 않고 문서를 먼저 보여 줍니다.
- 문서를 여는 데 시간이 걸리면 문서 영역 위에 가는 진행 막대가 흐릅니다.

## 1.1.1

### 고친 문제

- 설치·제거 프로그램이나 Windows가 앱을 닫는 도중 오류가 나면 앱이 창 없이 남아 설치가 멈출 수 있던 문제를 고쳤습니다. 이제 닫히는 중에 오류가 나면 바로 끝납니다.

## 1.1.0

### 새 기능

- 문서를 인쇄합니다(`Ctrl+P`). 인쇄 미리보기에서 프린터와 용지, 여백을 고릅니다.
- 문서를 PDF나 HTML 파일로 내보냅니다. 더보기(`⋯`) 메뉴의 **PDF로 내보내기**, **HTML로 내보내기**에서 저장 위치를 고릅니다.
- 내보낸 HTML은 파일 하나입니다. 스타일과 그림이 파일 안에 들어 있어 그 파일만 보내도 그대로 보입니다.
- 인쇄물과 내보낸 파일은 앱이 어두운 테마여도 항상 밝은 테마로 만듭니다.

### 고친 문제

- 권한이 다른 계정으로 실행한 창이 켜져 있을 때 앱이 시작하지 못할 수 있던 문제를 고쳤습니다.

## 1.0.0

첫 정식 버전입니다.

### 문서 보기

- 트리에서 md 파일을 고르면 바로 렌더링해 보여 줍니다. 표, 작업 목록, 각주, 제목 앵커, 상대 경로 그림을 지원합니다.
- 코드 블록을 언어에 맞춰 색으로 구분합니다.
- `mermaid` 코드 블록을 그림으로 보여 줍니다(상태 다이어그램, 순서도 등).
- 문서 안에서 글자를 찾습니다(`Ctrl+F`).
- 목차 패널에서 제목을 골라 그 위치로 이동합니다(`Ctrl+Shift+B`).
- 문서를 확대·축소합니다(`Ctrl+=`, `Ctrl+-`, `Ctrl+0`, `Ctrl+마우스 휠`).
- 테마를 밝게, 어둡게, 시스템 설정 따르기 가운데 고릅니다.
- 링크를 누르면 웹·메일은 기본 앱으로, 다른 md 문서는 앱 안에서, 그 밖의 파일은 탐색기에서 위치를 엽니다.
- 문서 안의 스크립트는 실행하지 않습니다.

### 폴더와 파일 찾기

- 드라이브, 폴더, md 파일을 한 트리에서 봅니다. 주소 표시줄에 경로를 입력해 바로 이동할 수 있습니다.
- 자주 가는 폴더를 즐겨찾기에 넣어 트리 맨 위에 둡니다.
- 펼쳐 둔 폴더와 열어 둔 문서가 바깥에서 바뀌면 저절로 다시 읽습니다. `F5`로 직접 새로 고칠 수도 있습니다.
- 탐색기에서 md 파일이나 폴더를 창에 끌어다 놓아 엽니다.
- 탐색기 우클릭 메뉴 "MDFileViewer로 열기"를 등록하고 해제합니다.

### 문서 탭과 창

- 여러 문서를 탭으로 엽니다. 트리에서 한 번 누르면 미리보기 탭, 두 번 누르면 고정 탭입니다.
- 다시 실행하면 지난번에 열어 둔 탭과 폴더를 되살립니다.
- 이미 창이 열려 있으면 새 창을 띄우지 않고 그 창의 탭으로 엽니다. 더보기(`⋯`) 메뉴의 **창 하나로 열기**를 끄면 실행할 때마다 새 창을 엽니다.

### 편집

- 편집 모드(`Ctrl+E`)에서 왼쪽에 쓰고 오른쪽 미리보기로 바로 확인합니다.
- 저장하지 않은 변경이 있으면 탭이나 창을 닫기 전에 묻습니다.
- 파일의 인코딩(UTF-8, UTF-16, CP949)과 줄 끝 형식을 그대로 지켜 저장합니다.
- 다른 프로그램이 같은 파일을 바꿨으면 덮어쓰기 전에 묻습니다.

### 그 밖에

- `F1` 도움말에서 Markdown 문법 15가지의 작성 예시와 결과, 단축키를 봅니다.
- 창 위치와 크기, 패널 너비, 테마 같은 설정을 기억합니다.
- 설치 파일과 설치 없이 쓰는 포터블 exe로 배포합니다.
