# 릴리즈 노트

MDFileViewer의 버전별 변경 내용입니다. 최신 버전이 위에 있습니다.

## 1.1.1

### 고친 문제

- 설치·제거 프로그램이나 Windows가 앱을 닫는 도중 오류가 나면 앱이 창 없이 남아 설치가 멈출 수 있던 문제를 고쳤습니다. 이제 닫히는 중에 오류가 나면 바로 끝납니다.

## 1.1.0

### 새 기능

- 문서를 인쇄합니다(`Ctrl+P`). 인쇄 미리보기에서 프린터와 용지, 여백을 고릅니다.
- 문서를 PDF나 HTML 파일로 내보냅니다. 더보기(`⋯`) 메뉴의 **PDF로 내보내기**, **HTML로 내보내기**에서 저장 위치를 고릅니다.
- 내보낸 HTML은 파일 하나입니다. 스타일과 그림이 파일 안에 들어 있어 그 파일만 보내도 그대로 보입니다.
- 인쇄물과 내보낸 파일은 앱이 어두운 테마여도 항상 밝은 테마로 만듭니다.

### 고친 문제

- 권한이 다른 계정으로 실행한 창이 켜져 있을 때 앱이 시작하지 못할 수 있던 문제를 고쳤습니다.

## 1.0.0

첫 정식 버전입니다.

### 문서 보기

- 트리에서 md 파일을 고르면 바로 렌더링해 보여 줍니다. 표, 작업 목록, 각주, 제목 앵커, 상대 경로 그림을 지원합니다.
- 코드 블록을 언어에 맞춰 색으로 구분합니다.
- `mermaid` 코드 블록을 그림으로 보여 줍니다(상태 다이어그램, 순서도 등).
- 문서 안에서 글자를 찾습니다(`Ctrl+F`).
- 목차 패널에서 제목을 골라 그 위치로 이동합니다(`Ctrl+Shift+B`).
- 문서를 확대·축소합니다(`Ctrl+=`, `Ctrl+-`, `Ctrl+0`, `Ctrl+마우스 휠`).
- 테마를 밝게, 어둡게, 시스템 설정 따르기 가운데 고릅니다.
- 링크를 누르면 웹·메일은 기본 앱으로, 다른 md 문서는 앱 안에서, 그 밖의 파일은 탐색기에서 위치를 엽니다.
- 문서 안의 스크립트는 실행하지 않습니다.

### 폴더와 파일 찾기

- 드라이브, 폴더, md 파일을 한 트리에서 봅니다. 주소 표시줄에 경로를 입력해 바로 이동할 수 있습니다.
- 자주 가는 폴더를 즐겨찾기에 넣어 트리 맨 위에 둡니다.
- 펼쳐 둔 폴더와 열어 둔 문서가 바깥에서 바뀌면 저절로 다시 읽습니다. `F5`로 직접 새로 고칠 수도 있습니다.
- 탐색기에서 md 파일이나 폴더를 창에 끌어다 놓아 엽니다.
- 탐색기 우클릭 메뉴 "MDFileViewer로 열기"를 등록하고 해제합니다.

### 문서 탭과 창

- 여러 문서를 탭으로 엽니다. 트리에서 한 번 누르면 미리보기 탭, 두 번 누르면 고정 탭입니다.
- 다시 실행하면 지난번에 열어 둔 탭과 폴더를 되살립니다.
- 이미 창이 열려 있으면 새 창을 띄우지 않고 그 창의 탭으로 엽니다. 더보기(`⋯`) 메뉴의 **창 하나로 열기**를 끄면 실행할 때마다 새 창을 엽니다.

### 편집

- 편집 모드(`Ctrl+E`)에서 왼쪽에 쓰고 오른쪽 미리보기로 바로 확인합니다.
- 저장하지 않은 변경이 있으면 탭이나 창을 닫기 전에 묻습니다.
- 파일의 인코딩(UTF-8, UTF-16, CP949)과 줄 끝 형식을 그대로 지켜 저장합니다.
- 다른 프로그램이 같은 파일을 바꿨으면 덮어쓰기 전에 묻습니다.

### 그 밖에

- `F1` 도움말에서 Markdown 문법 15가지의 작성 예시와 결과, 단축키를 봅니다.
- 창 위치와 크기, 패널 너비, 테마 같은 설정을 기억합니다.
- 설치 파일과 설치 없이 쓰는 포터블 exe로 배포합니다.
