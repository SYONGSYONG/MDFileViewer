# MDFileViewer 사용 매뉴얼

**버전 0.1.0** · 2026-11-18

MDFileViewer는 로컬 폴더의 Markdown 파일을 **찾고 → 고르고 → 바로 읽는** Windows 데스크톱 뷰어입니다.
왼쪽 트리에서 폴더를 펼치면 그 안의 하위 폴더와 md 파일이 함께 보이고, md 파일을 고르면 오른쪽 뷰어에 렌더링된 문서가 나타납니다.

> **이 버전에서 할 수 있는 것** — 0.1.0은 문서를 **보는** 기능(트리, 뷰어, 링크, 주소 표시줄, 새로고침)까지 들어 있습니다.
> 줌 버튼, 어두운 테마, 편집, 도움말 창, 탐색기 우클릭 메뉴, 설정 저장은 다음 버전에서 추가합니다.
> 이 매뉴얼은 **지금 동작하는 기능만** 설명하고, 예정된 기능은 [앞으로 추가될 기능](#앞으로-추가될-기능)에 따로 모았습니다.

## 시작하기

### 설치 및 실행

**필요한 것**

| 항목 | 내용 |
|------|------|
| 운영 체제 | Windows 11 (64비트). Windows 10도 동작을 목표로 하지만 아직 확인하지 않았습니다. |
| WebView2 Runtime | 문서를 표시하는 데 쓰는 Microsoft Edge WebView2 Runtime. Windows 11에는 기본으로 설치되어 있습니다. |
| .NET | 따로 설치하지 않습니다. 배포본 안에 들어 있습니다. |

**배포 방식 두 가지**

| 방식 | 파일 | 이렇게 씁니다 |
|------|------|---------------|
| 포터블 | `MDFileViewer-Portable-<버전>.exe` | 설치하지 않습니다. 파일 하나를 원하는 폴더(USB 포함)에 복사하고 더블클릭해 실행합니다. 파일 이름을 바꿔도 동작합니다. |
| 설치 파일 | `MDFileViewer-Setup-<버전>.exe` | 실행하면 설치 마법사가 열립니다. 관리자 권한 없이 **현재 사용자에게만** 설치합니다. |

> **권장** — 혼자 쓰는 PC에서 계속 쓸 거라면 **설치 파일**을 권합니다. 시작 메뉴에 등록되고, 포터블보다 처음 실행이 빠르며,
> Windows 설정에서 깔끔하게 제거할 수 있습니다. 여러 PC를 옮겨 다니거나 설치가 막힌 PC에서는 **포터블**이 편합니다.

**포터블로 실행하기**

1. `MDFileViewer-Portable-<버전>.exe`를 원하는 폴더에 복사합니다.
2. 더블클릭해 실행합니다.
3. **처음 실행할 때만** 몇 초(측정 예: 약 12초) 더 걸립니다. 실행에 필요한 파일을 임시 폴더(`%TEMP%\.net`)에 풀기 때문입니다.
   두 번째 실행부터는 풀어 둔 파일을 다시 쓰므로 빨라집니다.

**설치 파일로 설치하기**

1. `MDFileViewer-Setup-<버전>.exe`를 실행합니다. 설치 마법사는 한국어로 나옵니다.
2. 설치 위치를 확인합니다. 기본 위치는 `%LOCALAPPDATA%\Programs\MDFileViewer`입니다.
3. "바탕 화면에 바로 가기 만들기"는 기본으로 선택되어 있습니다. 필요 없으면 선택을 풉니다.
4. 설치가 끝나면 마지막 화면에서 바로 실행할 수 있습니다.
5. 이후에는 **시작 메뉴 → MDFileViewer**로 실행합니다.

> **알아둘 것** — 같은 버전이나 새 버전의 설치 파일을 다시 실행하면 기존 설치 위에 덮어씁니다(따로 지우지 않아도 됩니다).
> 제거는 **Windows 설정 → 앱 → 설치된 앱 → MDFileViewer → 제거**에서 합니다.

**이 매뉴얼 파일**

배포 폴더에는 이 매뉴얼이 `manual_<버전>.md`로 함께 들어 있습니다. MDFileViewer로 그 폴더를 열면 매뉴얼도 앱 안에서 바로 읽을 수 있습니다.

### 명령줄로 시작하기

폴더나 md 파일의 경로를 넘겨 실행하면 그 위치에서 시작합니다. 바로 가기의 "대상" 칸이나 명령 프롬프트에서 씁니다.

```powershell
MDFileViewer.exe "D:\Docs"              # 그 폴더를 트리에서 펼쳐 선택
MDFileViewer.exe "D:\Docs\guide.md"     # 그 파일을 트리에서 선택하고 문서를 연다
MDFileViewer.exe "\\server\share\docs"  # 네트워크 공유 폴더도 됩니다
```

| 넘긴 것 | 동작 |
|---------|------|
| 아무것도 없음 | "내 PC"만 보이는 상태로 시작합니다. 마지막에 보던 폴더를 기억하지 않습니다(설정 저장은 예정 기능). |
| 폴더 경로 | 트리를 그 폴더까지 펼치고 선택한 뒤, 그 폴더도 펼쳐 안의 하위 폴더와 md 파일을 보여 줍니다. |
| md 파일 경로 (`.md`, `.markdown`) | 그 파일이 있는 폴더까지 펼치고 파일을 선택해 문서를 엽니다. |
| md가 아닌 파일 경로 | 그 파일이 있는 폴더를 펼쳐 선택합니다. 파일 자체는 열지 않습니다. |
| 없는 경로 | "경로를 찾을 수 없음" 창에 "경로를 찾을 수 없습니다: (경로)"를 보여 준 뒤 "내 PC" 상태로 계속 실행합니다. |
| 상대 경로 (`docs\a.md`) | 실행한 위치(현재 작업 폴더)를 기준으로 해석합니다. |

- 경로 앞뒤의 따옴표는 알아서 떼어 냅니다. `"C:\"`처럼 끝의 `\"` 때문에 `C:"`로 잘려 들어온 경로도 `C:\`로 고쳐 씁니다.
- 경로는 **첫 번째 하나만** 씁니다. 두 번째 이후 인수는 무시합니다.
- 프로그램을 여러 번 실행하면 창이 여러 개 뜹니다. 이미 떠 있는 창으로 모으지 않습니다.

### 화면 구성

```
+--------------------------------------------------------------------+
| guide.md - MDFileViewer                                  _  [ ]  X |
+--------------------------------------------------------------------+
| (1)  [open]  [ D:\Docs                                           ] |
+----------------------+---+-----------------------------------------+
| (2)                  |(3)| (4)                                     |
|  v [PC]              |   |                                         |
|     > [C:]           |   |   # Title                               |
|     v [D:]           |   |                                         |
|        v Docs        |   |   Rendered document text ...            |
|           > images   |   |                                         |
|             guide.md |   |   | table | ... |                       |
|             notes.md |   |                                         |
+----------------------+---+-----------------------------------------+
| (5)  D:\Docs\guide.md   UTF-8   CRLF   4.2 KB   2026-11-17 15:30   |
+--------------------------------------------------------------------+
```

| 번호 | 영역 | 하는 일 |
|------|------|---------|
| (1) | 도구 모음 | 왼쪽은 **폴더 열기** 버튼(`Ctrl+O`), 오른쪽은 **주소 표시줄**입니다(그림의 `[open]`이 폴더 열기 버튼). 주소 표시줄에는 지금 선택한 폴더의 경로가 보이고, 경로를 입력해 이동할 수도 있습니다. |
| (2) | 트리 | "내 PC"(그림의 `[PC]`) 아래 드라이브(`[C:]`, `[D:]`)와 폴더, 폴더 안의 md 파일을 보여 줍니다. 여기서 md 파일을 고르면 문서가 열립니다. |
| (3) | 분할선 | 마우스로 끌어 트리와 뷰어의 너비를 바꿉니다. 트리는 160 이하로, 뷰어는 320 이하로 줄어들지 않습니다. |
| (4) | 뷰어 | 고른 md 파일을 렌더링해 보여 줍니다. 문서를 고르기 전에는 "왼쪽 트리에서 md 파일을 선택하세요"가 보입니다. |
| (5) | 상태 표시줄 | 열린 문서의 경로, 인코딩, 줄 끝, 크기, 수정 시각을 보여 줍니다. 잠깐 보이는 안내 메시지도 여기에 나옵니다. 자세한 내용은 [상태 표시줄](#상태-표시줄)을 보세요. |

**창 제목**은 상황에 따라 바뀝니다.

| 상황 | 제목 |
|------|------|
| 문서가 열려 있음 | `guide.md - MDFileViewer` |
| 문서 없이 폴더만 선택함 | `Docs - MDFileViewer` (드라이브 루트면 `C:\ - MDFileViewer`) |
| "내 PC"를 선택했고 문서가 없음 | `MDFileViewer` |

### 창 크기와 고DPI 모니터

- 창은 처음에 1440 × 900 크기로, 마우스 포인터가 있는 모니터의 가운데에 뜹니다. 최소 크기는 900 × 560입니다.
- 모니터 배율(100%, 150%, 200% 등)에 맞춰 선명하게 그립니다(Per-Monitor V2). 배율이 다른 모니터로 창을 옮겨도 흐려지지 않습니다.
- 배율이 커서 처음 크기가 화면(작업 표시줄을 뺀 영역)에 들어가지 않으면, 화면의 90% 크기로 줄여 가운데에 놓습니다.
  화면에 들어가는 크기면 그대로 둡니다.
- 창 위치, 크기, 트리 너비는 아직 기억하지 않습니다. 다음 실행 때 다시 처음 크기로 뜹니다(설정 저장은 예정 기능).

## 트리에서 파일 찾기

### 사용 절차

1. 트리 맨 위의 **내 PC**를 펼치면 드라이브 목록이 나옵니다.
2. 드라이브와 폴더를 펼쳐 내려갑니다. 폴더 이름 앞의 화살표(▸)를 누르거나, 폴더를 더블클릭하거나, 키보드 `→`를 누릅니다.
3. 폴더 안에는 **하위 폴더가 먼저, 그다음 md 파일**이 보입니다.
4. md 파일을 누르면(또는 키보드로 옮겨 가면) 오른쪽 뷰어에 문서가 열립니다.

> **팁** — 깊은 폴더는 펼쳐 내려가는 것보다 [주소 표시줄](#주소-표시줄)에 경로를 붙여 넣는 편이 빠릅니다.
> 탐색기 주소 줄에서 경로를 복사해 붙여 넣고 `Enter`를 누르면 그 폴더까지 한 번에 펼쳐집니다.

### 트리에 보이는 것

**드라이브**

- "내 PC" 아래에 이 PC의 드라이브가 보입니다. 이름은 `볼륨 이름 (C:)` 형식이고, 볼륨 이름이 없으면 종류 이름(로컬 디스크, 이동식 디스크,
  네트워크 드라이브, CD 드라이브, RAM 디스크)을 씁니다. 예: `로컬 디스크 (C:)`, `Data (D:)`.
- **3초 안에 응답하지 않는 드라이브는 목록에서 뺍니다.** 연결이 끊긴 네트워크 드라이브나 디스크를 넣지 않은 CD 드라이브 때문에 트리가 멈추지 않게 하기 위해서입니다.
  나중에 연결되면 "내 PC"를 선택하고 `F5`를 누릅니다.
- 드라이브와 폴더는 종류에 맞는 아이콘(하드 디스크, 이동식 디스크, 네트워크, CD, 폴더)으로 구별합니다.

**폴더와 md 파일**

- 확장자가 `.md` 또는 `.markdown`인 파일만 보입니다(대소문자 구분 없음). 그 밖의 파일은 트리에 나오지 않습니다.
- 정렬은 폴더 먼저, md 파일 다음이고, 각각 이름순(대소문자 구분 없음)입니다.
- **숨김·시스템 폴더와 파일은 보이지 않습니다.** 단, 주소 표시줄이나 명령줄로 숨김 폴더 안을 직접 찾아가면 그 경로는 트리에 보여 줍니다.
- 폴더를 처음 펼칠 때 그 안을 읽습니다. 그 사이 폴더 아래에 "불러오는 중…"이 잠깐 보입니다.
- 폴더를 펼치면 그 안의 하위 폴더 중 **하위 폴더도 md 파일도 없는 폴더**는 잠시 뒤 펼침 화살표가 사라집니다.

**들어갈 수 없는 폴더**

| 상황 | 트리 표시 |
|------|-----------|
| 권한이 없어 열 수 없는 폴더 | 자물쇠 아이콘. 마우스를 올리면 "접근 권한이 없습니다"가 보입니다. 펼쳐도 아무것도 나오지 않습니다. |
| 그 밖의 이유로 읽지 못한 폴더(이미 지워짐, 연결 끊김 등) | 펼쳐도 비어 있습니다. |

**네트워크 공유 폴더 (UNC 경로)**

- `\\server\share`처럼 드라이브 문자 없는 네트워크 경로는 처음에는 트리에 없습니다.
- 주소 표시줄이나 명령줄로 그 경로에 가면 "내 PC" 맨 아래에 `\\server\share` 항목이 생기고 그 아래로 펼쳐집니다.

### 폴더 열기 (Ctrl+O)

1. 도구 모음의 **폴더 열기** 버튼을 누르거나 `Ctrl+O`를 누릅니다.
2. Windows 폴더 선택 창이 열립니다. 폴더를 선택해 둔 상태면 그 폴더에서 시작합니다.
3. 폴더를 고르면 트리를 그 폴더까지 펼치고 선택한 뒤, 그 폴더도 펼쳐 안을 보여 줍니다.

### 새로고침 (F5)

트리는 폴더를 처음 펼칠 때 읽은 내용을 보여 줍니다. 다른 프로그램에서 파일을 만들거나 지웠다면 `F5`로 다시 읽습니다.

| 선택한 것 | `F5`를 누르면 |
|-----------|---------------|
| 폴더 | 그 폴더의 내용을 다시 읽습니다. |
| md 파일 | 그 파일이 있는 폴더를 다시 읽고 **같은 파일을 계속 선택**합니다. 파일이 지워졌으면 폴더를 선택합니다. |
| 내 PC | 드라이브 목록을 다시 읽습니다. USB를 꽂았거나 네트워크 드라이브를 연결한 뒤에 씁니다. |

- 문서가 열려 있으면 문서도 **다시 읽어 표시**합니다. 스크롤 위치는 그대로 유지하고, 큰 파일 확인 창도 다시 묻지 않습니다.
  다른 편집기에서 고친 내용을 바로 확인할 때 편리합니다.
- 다시 읽는 것은 선택한 폴더 **한 단계**뿐입니다. 그 아래 이미 펼쳐 둔 하위 폴더는 그 폴더를 선택하고 다시 `F5`를 누릅니다.

### 알아둘 것

- 폴더를 선택해도 열려 있던 문서는 닫히지 않습니다. 다른 md 파일을 고를 때까지 그대로 보입니다.
- 트리 오른쪽 클릭 메뉴는 아직 없습니다.
- 트리를 누르거나 키보드로 위아래로 움직여도 가로 스크롤 위치는 바뀌지 않습니다. 이름이 긴 폴더를 읽을 때만 가로 스크롤 막대를 직접 움직입니다.

## 주소 표시줄

### 사용 절차

1. 도구 모음 오른쪽의 주소 표시줄을 누릅니다. 지금 선택한 폴더의 경로가 들어 있습니다("내 PC"를 선택했으면 비어 있습니다).
2. 가고 싶은 폴더나 md 파일의 경로를 입력하거나 붙여 넣습니다.
3. `Enter`를 누릅니다.

### 입력에 따른 동작

| 입력 | 동작 |
|------|------|
| 폴더 경로 (`D:\Docs`) | 트리를 그 폴더까지 펼쳐 선택하고, 그 폴더도 펼칩니다. |
| md 파일 경로 (`D:\Docs\guide.md`) | 트리에서 그 파일을 선택하고 문서를 엽니다. |
| md가 아닌 파일 경로 (`D:\Docs\data.xlsx`) | 그 파일이 있는 폴더로 갑니다. 파일은 열지 않습니다. |
| 네트워크 경로 (`\\server\share\docs`) | "내 PC" 맨 아래에 공유 항목을 만들고 그 폴더로 갑니다. |
| 상대 경로 (`..\Docs`) | 프로그램을 실행한 위치를 기준으로 해석합니다. |
| 없는 경로 | 아무 곳으로도 가지 않고, 상태 표시줄에 "경로를 찾을 수 없습니다: (입력한 내용)"을 3초 동안 보여 줍니다. |

> **팁** — 탐색기의 **경로로 복사**로 복사한 경로처럼 앞뒤에 따옴표(`"D:\Docs\guide.md"`)가 붙어 있어도
> 그대로 붙여 넣으면 됩니다. 따옴표는 알아서 떼어 냅니다.

## 문서 보기

### 지원하는 Markdown 문법

GitHub에서 쓰는 Markdown 문법을 대부분 그대로 보여 줍니다.

| 문법 | 예 | 비고 |
|------|----|------|
| 제목 | `# 제목` ~ `###### 제목` | 제목마다 바로 가기용 앵커가 자동으로 붙습니다(한글 제목 포함). |
| 강조 | `**굵게**`, `*기울임*`, `~~취소선~~` | |
| 목록 | `- 항목`, `1. 항목` | 들여쓰기로 중첩 |
| 작업 목록 | `- [ ] 할 일`, `- [x] 한 일` | 체크 상자로 보입니다(보기 전용). |
| 표 | `\| 열 \| 열 \|` | 정렬(`:---`, `:---:`, `---:`) 지원 |
| 코드 | `` `코드` ``, ```` ``` ```` 블록 | 고정폭 글꼴로 보입니다. 언어별 색 구분은 하지 않습니다. |
| 인용 | `> 인용문` | |
| 링크 | `[글자](주소)`, `<https://…>`, 맨 주소 | 맨 주소(`https://example.com`)도 자동으로 링크가 됩니다. 누르면 어떻게 되는지는 [링크 누르기](#링크-누르기)를 보세요. |
| 각주 | `본문[^1]` / `[^1]: 설명` | 문서 끝에 각주가 모입니다. |
| 그림 | `![설명](images/a.png)` | 아래 [그림](#그림)을 보세요. |
| 구분선 | `---` | |
| YAML 머리말 | 파일 맨 앞의 `---` … `---` 블록 | 화면에 보이지 않습니다. |
| HTML | `<details>`, `<kbd>`, `<br>` 등 | 아래 [HTML과 보안](#html과-보안)을 보세요. |

- 본문 너비는 읽기 편하도록 최대 860 픽셀로 제한하고, 창이 넓으면 가운데에 놓습니다. 글자 크기는 16입니다.
- 지금은 밝은 테마만 있습니다(어두운 테마는 예정 기능).

### 그림

| 그림 주소 | 표시 |
|-----------|------|
| 상대 경로 (`images/a.png`, `../assets/b.png`) | 보입니다. md 파일이 있는 폴더를 기준으로 찾습니다. 같은 드라이브(또는 같은 네트워크 공유) 안에 있어야 합니다. |
| `https://` 주소 | 보입니다. 이때만 인터넷에 연결합니다. |
| `data:` 주소(문서 안에 넣은 그림) | 보입니다. |
| `http://` 주소 | 보이지 않을 수 있습니다. 문서가 보안 연결(https)로 표시되어 보안 연결이 아닌 그림을 막기 때문입니다. |
| `C:\…` 같은 절대 경로, `file:` 주소 | 보이지 않습니다. 상대 경로로 바꿔 씁니다. |

### HTML과 보안

- md 파일 안의 HTML(`<details>`, `<kbd>`, `<sub>` 등)은 그대로 보여 줍니다.
- **문서 안의 스크립트는 실행하지 않습니다.** `<script>`, 이벤트 속성(`onclick` 등)은 동작하지 않습니다.
- 다른 페이지를 끼워 넣는 `<iframe>`, `<object>`와 입력 양식 `<form>`은 막습니다.
- 문서 안의 `<meta>` 태그는 효과 없이 글자로 보입니다(문서가 화면을 다른 곳으로 옮기지 못하게 하기 위해서입니다).
- 원격 그림을 표시할 때를 빼면 네트워크에 연결하지 않고, 사용 통계를 모으지 않습니다.

### 큰 파일

5 MB보다 큰 파일을 열 때는 먼저 묻습니다.

> **큰 파일 열기**\
> 파일이 큽니다(12.3MB). 여는 데 시간이 걸릴 수 있습니다. 열까요?\
> `[ 열기 ]` `[ 취소 ]`

- **열기**(`Enter`)를 누르면 엽니다. **취소**(`Esc`)를 누르면 열지 않고, 보고 있던 문서가 그대로 남습니다.
- `F5`로 다시 읽을 때는 묻지 않습니다(이미 열기로 한 파일이기 때문입니다).

### 인코딩과 줄 끝

파일의 인코딩을 알아서 판별해 읽습니다. 따로 고를 필요가 없습니다.

| 파일 | 상태 표시줄 |
|------|-------------|
| UTF-8 (BOM 없음) — 요즘 편집기의 기본 | `UTF-8` |
| UTF-8 (BOM 있음) — 메모장 "UTF-8(BOM)" 등 | `UTF-8 (BOM)` |
| UTF-16 리틀 엔디언 / 빅 엔디언 (BOM 있음) | `UTF-16 LE` / `UTF-16 BE` |
| CP949 (EUC-KR 확장, 한국어 Windows의 예전 기본 "ANSI") | `CP949` |

- 판별 순서: BOM이 있으면 BOM을 따릅니다 → 없으면 UTF-8로 읽어 보고 → UTF-8이 아니면 CP949로 읽습니다.
- 줄 끝은 `CRLF`(Windows)와 `LF`(Linux·macOS·Git 기본) 중 더 많이 쓰인 쪽을 보여 줍니다. 같거나 줄 바꿈이 없으면 `CRLF`로 표시합니다.
- **글자가 깨져 읽을 수 없는 부분**이 있으면 그 자리를 `�`로 바꿔 보여 주고, 상태 표시줄 오른쪽에 빨간 글씨로
  "일부 글자를 읽을 수 없습니다 — 저장할 수 없습니다"가 나옵니다. 파일 일부가 손상됐거나 위 인코딩이 아닌 파일(예: 일본어 Shift-JIS)일 때입니다.
  보기에는 지장이 없습니다. "저장할 수 없습니다"는 편집 기능(예정)이 생기면 이 파일을 저장하지 못하게 막는다는 뜻입니다 — 그대로 저장하면 원래 내용을 잃기 때문입니다.
- 이 버전은 md 파일을 **절대 고쳐 쓰지 않습니다.** 보기만 합니다.

### 상태 표시줄

문서를 열면 상태 표시줄에 왼쪽부터 다음 순서로 보입니다. 값이 없는 칸은 접혀서 보이지 않습니다.

| 칸 | 예 | 설명 |
|----|----|------|
| 안내 메시지 | `파일을 찾을 수 없습니다: a.md` | 링크·주소 표시줄 결과 등을 **3초 동안** 보여 줍니다. 그동안은 경로 칸 대신 보입니다. |
| 경로 | `D:\Docs\guide.md` | 열린 문서의 전체 경로. 너무 길면 뒷부분을 `…`로 줄여 보여 줍니다. |
| 인코딩 | `UTF-8` | [인코딩과 줄 끝](#인코딩과-줄-끝) 참고 |
| 줄 끝 | `CRLF` | |
| 크기 | `512 B`, `4.2 KB`, `12.3 MB` | 1024 단위 |
| 수정 시각 | `2026-11-17 15:30` | 파일의 마지막 수정 시각(PC의 시간대) |
| 경고 | `일부 글자를 읽을 수 없습니다 — 저장할 수 없습니다` | 빨간 글씨. 해당할 때만 보입니다. |

### 확대·축소

- 뷰어 위에서 `Ctrl`을 누른 채 **마우스 휠**을 굴리면 문서가 커지고 작아집니다.
- 지금은 휠로만 됩니다. `Ctrl+=`, `Ctrl+-`, `Ctrl+0` 단축키와 줌 버튼, 배율 표시는 예정 기능입니다.
- 정해 둔 배율은 저장하지 않습니다. 다시 실행하면 100%로 시작합니다.

### 글자 복사

- 뷰어에서 마우스로 글자를 끌어 선택한 뒤 `Ctrl+C`를 누르거나, 오른쪽 클릭 → **복사**를 고릅니다.
- 오른쪽 클릭 메뉴에는 "복사"만 나옵니다. 아무것도 선택하지 않고 오른쪽 클릭하면 메뉴가 뜨지 않습니다.
- 인쇄, 페이지 안 찾기(`Ctrl+F`), 브라우저 새로고침(`Ctrl+R`) 같은 웹 브라우저 기능은 꺼 두었습니다.

## 링크 누르기

### 링크 종류별 동작

문서 안의 링크를 누르면 링크 종류에 따라 다음처럼 처리합니다.

| 링크 | 예 | 동작 |
|------|----|------|
| 웹 주소 | `https://example.com`, `http://…` | **기본 브라우저**에서 엽니다. |
| 메일 주소 | `mailto:someone@example.com` | 기본 **메일 앱**에서 새 메일을 엽니다. |
| 같은 문서의 제목 | `#설치-방법` | 그 제목으로 스크롤합니다. |
| 다른 md 파일 | `other.md`, `../guide.md#설치` | 트리에서 그 파일을 선택하고 앱 안에서 엽니다. `#제목`이 붙어 있으면 그 위치로 스크롤합니다. |
| md가 아닌 로컬 파일 | `data.xlsx`, `setup.bat` | **실행하지 않고** 탐색기를 열어 그 파일을 선택해 보여 줍니다. |
| 로컬 폴더 | `images/` | 탐색기를 열어 그 폴더를 선택해 보여 줍니다. |
| 없는 파일 | `missing.md` | 상태 표시줄에 "파일을 찾을 수 없습니다: missing.md"를 3초 동안 보여 줍니다. |
| 그 밖의 주소 | `file:///…`, `javascript:…`, `ms-settings:…` 등 | 아무 일도 일어나지 않습니다(보안상 막습니다). |

> **왜 로컬 파일을 실행하지 않나요?** — 받은 md 문서에 `setup.bat` 같은 링크가 있을 때 한 번 누른 것만으로 프로그램이 실행되면 위험합니다.
> 그래서 웹·메일이 아닌 것은 탐색기에서 **선택만** 해 주고, 실행할지는 사용자가 탐색기에서 직접 정하게 했습니다.

### 알아둘 것

- 상대 경로 링크(`other.md`, `../a.md`)는 지금 문서가 있는 폴더를 기준으로 찾습니다. 같은 드라이브(또는 같은 네트워크 공유)를 벗어나는 링크는 막습니다.
- 파일 이름에 공백이 있으면 `%20`으로 쓰거나(`my%20file.md`) `<my file.md>`처럼 꺾쇠로 감쌉니다.
- 새 창으로 열도록 만든 링크(`target="_blank"`)도 똑같이 처리합니다. 앱 안에 새 창이 생기지 않습니다.
- 링크는 **사용자가 직접 눌렀을 때만** 엽니다. 문서가 스스로 다른 곳으로 이동하거나 창을 여는 일은 없습니다.
- 브라우저나 탐색기를 열지 못하면 상태 표시줄에 "링크를 열지 못했습니다"가 나옵니다.

## 앱이 남기는 파일

MDFileViewer가 PC에 쓰는 파일은 아래 두 가지뿐입니다. md 파일은 읽기만 하고 고치지 않습니다.

| 위치 | 내용 | 비고 |
|------|------|------|
| `%LOCALAPPDATA%\MDFileViewer\logs\yyyyMMdd.log` | 실행 기록과 오류 내용. 하루에 파일 하나 | **7일이 지난 로그는 자동으로 지웁니다.** 문제를 알릴 때 이 파일을 함께 보내 주세요. |
| `%LOCALAPPDATA%\MDFileViewer\WebView2\` | 문서 표시용 브라우저 엔진(WebView2)의 작업 데이터 | 지워도 다음 실행 때 다시 만듭니다. |

- 설정 파일은 아직 만들지 않습니다(설정 저장은 예정 기능).
- 설치 파일로 설치하면 Windows "설치된 앱" 목록에 쓰는 제거 정보가 등록되고, 제거하면 함께 지워집니다.
- **제거해도 `%LOCALAPPDATA%\MDFileViewer` 폴더는 남습니다.** 완전히 지우려면 제거한 뒤 이 폴더를 직접 지웁니다.
  포터블 실행 때 풀린 `%TEMP%\.net` 폴더도 필요 없으면 지워도 됩니다(다음 포터블 실행 때 다시 풉니다).

> **팁** — 탐색기 주소 줄에 `%LOCALAPPDATA%\MDFileViewer`를 입력하고 `Enter`를 누르면 바로 그 폴더가 열립니다.

## 문제 해결

### 실행하자마자 "WebView2 Runtime 필요" 창이 떠요

문서를 표시하는 데 필요한 Microsoft Edge WebView2 Runtime이 이 PC에 없을 때 나옵니다.

1. 창의 **다운로드 페이지 열기**를 누르면 Microsoft WebView2 다운로드 페이지가 브라우저에서 열리고 MDFileViewer는 종료됩니다.
   (**닫기**를 누르면 페이지를 열지 않고 종료합니다.)
2. 페이지에서 Evergreen 방식 설치 파일을 받아 설치합니다.
3. MDFileViewer를 다시 실행합니다.

Windows 11과 최신 Windows 10에는 보통 이미 설치되어 있습니다. 회사 PC에서 설치가 막혀 있으면 IT 담당자에게 요청합니다.

### 포터블 exe가 처음에 한참 있다가 떠요

정상입니다. 포터블 exe는 처음 실행할 때 필요한 파일을 `%TEMP%\.net`에 풀어 놓느라 몇 초 더 걸립니다. 두 번째 실행부터는 빨라집니다.
임시 폴더 정리 프로그램이 이 폴더를 지우면 다음 실행 때 다시 풉니다.

### 드라이브(네트워크 드라이브, USB)가 트리에 안 보여요

- 3초 안에 응답하지 않은 드라이브는 목록에서 뺍니다. 드라이브가 연결됐는지 탐색기에서 확인한 뒤, 트리에서 **내 PC**를 선택하고 `F5`를 누릅니다.
- 앱을 띄운 뒤에 USB를 꽂았거나 네트워크 드라이브를 연결했을 때도 같은 방법으로 다시 읽습니다.
- 드라이브 문자 없는 네트워크 공유(`\\server\share`)는 원래 목록에 없습니다. 주소 표시줄에 경로를 입력해 갑니다.

### 폴더 안에 파일이 있는데 트리에 안 보여요

- 트리는 **`.md`·`.markdown` 파일만** 보여 줍니다. `.txt` 등 다른 확장자는 나오지 않습니다.
- 숨김 속성이 있는 파일·폴더는 보이지 않습니다.
- 앱을 띄운 뒤에 만든 파일이면 그 폴더를 선택하고 `F5`를 누릅니다.

### 폴더에 자물쇠가 보이고 펼쳐지지 않아요

Windows 권한상 지금 사용자가 그 폴더를 읽을 수 없습니다("접근 권한이 없습니다"). 탐색기에서도 열리지 않는 폴더입니다.
MDFileViewer는 관리자 권한으로 실행하지 않으므로, 권한이 필요하면 폴더 소유자나 IT 담당자에게 요청합니다.

### "파일을 열 권한이 없습니다" / "다른 프로그램이 파일을 사용 중이라 열 수 없습니다"가 떠요

| 메시지 | 원인과 해결 |
|--------|-------------|
| 파일을 찾을 수 없습니다 | 트리를 읽은 뒤 파일이 지워졌거나 옮겨졌습니다. 폴더를 선택하고 `F5`를 누릅니다. |
| 파일을 열 권한이 없습니다 | 그 파일을 읽을 권한이 없습니다. 탐색기에서 파일 속성 → 보안을 확인합니다. |
| 다른 프로그램이 파일을 사용 중이라 열 수 없습니다 | 다른 프로그램이 파일을 독점해서 잡고 있습니다(예: 저장 중인 편집기, 동기화 중인 클라우드 폴더). 잠시 뒤 `F5`를 누릅니다. |
| 파일을 읽지 못했습니다 | 그 밖의 읽기 오류입니다. 네트워크 경로라면 연결 상태를 확인합니다. 자세한 내용은 로그에 남습니다. |

### 한글이 깨져 보이거나 "일부 글자를 읽을 수 없습니다"가 떠요

- UTF-8, UTF-16(BOM 있음), CP949만 자동으로 판별합니다. 그 밖의 인코딩(일본어 Shift-JIS, 중국어 GB2312 등)은 깨져 보입니다.
- 파일 일부가 손상됐을 때도 이 메시지가 나옵니다. 깨진 자리는 `�`로 보입니다.
- 해결하려면 그 파일을 다른 편집기(예: VS Code의 "인코딩하여 다시 열기" → "인코딩하여 저장")에서 UTF-8로 저장합니다.

### 그림이 안 보여요

- 그림 경로가 md 파일 기준 **상대 경로**인지 확인합니다. `C:\…`처럼 드라이브부터 쓴 절대 경로나 `file:` 주소는 표시하지 않습니다.
- 그림이 md 파일과 **다른 드라이브**에 있으면 표시하지 않습니다.
- `http://`(s 없음) 주소의 그림은 막힐 수 있습니다. `https://` 주소가 있으면 그쪽을 씁니다.
- 인터넷 그림은 인터넷에 연결돼 있어야 보입니다.

### 링크를 눌러도 아무 일도 안 일어나요

- `file:`, `javascript:` 같은 주소는 보안상 막습니다([링크 종류별 동작](#링크-종류별-동작) 참고). 로컬 파일은 상대 경로(`../docs/a.md`)로 씁니다.
- 링크가 다른 드라이브를 가리키면 막힙니다.
- 상태 표시줄에 "파일을 찾을 수 없습니다"가 잠깐 떴다면 링크한 파일이 없는 것입니다. 경로와 파일 이름(대소문자, 공백)을 확인합니다.

### `.bat`이나 `.exe` 링크를 눌렀는데 실행되지 않고 탐색기만 열려요

의도한 동작입니다. 보안을 위해 문서의 링크로는 프로그램을 실행하지 않고 탐색기에서 선택만 해 줍니다. 실행하려면 탐색기에서 직접 더블클릭합니다.

### 창이 화면보다 크게 떠요 / 너무 작게 떠요

- 처음 크기(1440 × 900)가 화면에 들어가지 않으면 화면의 90%로 줄여 띄웁니다. 그래도 맞지 않으면 창 테두리를 끌어 조절합니다.
- 창은 마우스 포인터가 있는 모니터에 뜹니다. 원하는 모니터에 포인터를 두고 실행합니다.
- 창 크기는 아직 기억하지 않습니다(예정 기능).

### "문서를 표시하지 못했습니다"가 떠요

문서 표시 엔진(WebView2)에 문제가 생긴 경우입니다. 앱은 엔진을 **자동으로 다시 띄워 문서를 다시 보여 줍니다**(새 문서를 열기 전까지 최대 3번).
그래도 계속 이 메시지가 나오면 MDFileViewer를 닫고 다시 실행합니다. 반복되면 로그 파일(`%LOCALAPPDATA%\MDFileViewer\logs`)을 함께 알려 주세요.

### "작업 중 오류가 났습니다" 창이 떠요

예상하지 못한 오류입니다. **확인**을 누르면 앱은 계속 쓸 수 있습니다. 같은 오류가 반복되면 그때 한 일과 로그 파일을 함께 알려 주세요.

### F1을 눌러도 도움말이 안 나와요

Markdown 문법 도움말 창은 다음 버전에서 추가합니다. 지금은 이 매뉴얼의 [지원하는 Markdown 문법](#지원하는-markdown-문법) 표를 참고합니다.

## 앞으로 추가될 기능

지금 버전에는 없고 다음 버전에서 차례로 추가할 기능입니다. 추가되면 이 매뉴얼에도 설명을 넣습니다.

| 기능 | 내용 |
|------|------|
| 뷰어 줌 | `+`·`−`·`100%` 버튼, `Ctrl+=`·`Ctrl+-`·`Ctrl+0` 단축키, 배율 표시 |
| 테마 | 밝은 / 어두운 / 시스템 설정 따라가기 |
| 편집 모드 | `Ctrl+E`로 편집기와 미리보기를 나란히 보며 고치기, `Ctrl+S` 저장, 저장하지 않고 닫을 때 확인 |
| 도움말 창 | `F1`로 Markdown 문법 도움말 열기 |
| 탐색기 우클릭 메뉴 | md 파일·폴더를 오른쪽 클릭 → "MDFileViewer로 열기" 등록·해제 |
| 설정 저장 | 창 위치·크기, 트리 너비, 테마, 마지막 폴더 기억 |
| 그 밖 | 상태 표시줄 커서 위치·"저장됨" 표시, 트리 오른쪽 클릭 메뉴 |
