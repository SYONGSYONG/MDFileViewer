# 00. 프로젝트 개요 — MDFileViewer

## 프로젝트 정의

MDFileViewer는 로컬 폴더의 Markdown 파일을 **찾고 → 고르고 → 바로 읽는** 흐름을 한 창에서 처리하는
**Windows 데스크톱 앱**이다. 필요할 때만 편집 모드로 넘어가 고칠 수 있다.

- 왼쪽 **탐색기 트리**에 폴더와 그 안의 **md 파일**을 함께 보여 주고, md 파일을 클릭하면
  오른쪽 **뷰어**에 렌더링된 문서를 보여 준다.
- 기본은 뷰어이고, 모드를 전환하면 **편집기 | 미리보기** 2분할 편집 모드가 된다.
- 밝은/어두운 테마, 뷰어 줌(기본 100%, +/− 단계), Markdown 문법 도움말을 제공한다.
- Windows 탐색기 우클릭 메뉴에서 그 위치를 기준으로 바로 시작할 수 있다.

사람이 해야 하는 실행 확인(끌어다 놓기·탐색기 메뉴·실행 중 Windows 앱 모드 변경), E2E 보강·성능·접근성·배포본 확인이다 — 순서는 `05-tasks.md` "남은 작업 순서".
아래는 여기까지 온 경과다. 명세 검토가 끝나 검토 항목 10건이 모두 제안대로 확정되었고(2026-11-17),
솔루션 골격과 PoC 6건(결과는 `02-specs.md` §11), Core의 파일 시스템·텍스트·명령줄·로그 서비스(Phase 2),
렌더링·문서 URL·뷰어 스크립트·링크 분류와 viewer 템플릿(Phase 3), 메인 창 보기 모드(Phase 4 — 트리·뷰어·링크·시작 인수·
전역 예외·WebView2 복구)를 만들었다(2026-11-17). 웹·로컬 파일 링크가 실제 브라우저·탐색기를 여는지는 사용자가 직접 확인했다
(`05-tasks.md` 4-6, 2026-11-18). Phase 4 실행 화면을 본 사용자 결정·지적으로 md 목록 창을 트리에 합쳤고(4-9), 트리 클릭 때 가로 스크롤이
움직이던 문제(4-10)와 배율이 큰 모니터에서 시작 창이 화면을 넘던 문제(4-11)를 고쳤다(2026-11-18). 사용자 요청으로 Phase 11의
배포 중 포터블 exe·설치 파일을 만드는 배치 파일과 README·사용법 매뉴얼(`docs/manual.md`)을 먼저 만들었다(11-6, 깨끗한 PC 확인 남음).
2026-11-18 사용자 요청으로 남은 기능(Phase 5~10)을 한 번에 구현하고, 즐겨찾기(F-16)와 문서 탭(F-17)을 범위에 넣었다. 전면 재검토에서
찾은 빈틈(스크립트 미실행 자동 검증, `Ctrl+휠` 범위 보정 등)은 모든 기능을 마친 뒤 보완한다. 작업은 `feature/remaining-features` 브랜치에서 한다.
2026-11-21 남아 있던 실행 확인을 E2E로 옮겨 33개를 모두 통과시켰다(줌 단축키·`Ctrl+휠`, 테마 전환·시스템 따르기·복원, 탭 고정, 덮어쓰기 확인, 큰 파일 취소).
Git 저장소는 `main` 브랜치로 관리하고, 원격 저장소 `origin`(GitHub `SYONGSYONG/MDFileViewer`, 공개)에 올린다(2026-11-18).
Phase 4 작업은 `feature/phase4-main-window` 브랜치에서 커밋해 `main`에 병합했다.

2026-11-22 Phase 6·9·10·11의 남은 확인과 함께 후속 기능(Phase 12)을 시작했다 — 뷰어 안 찾기(F-20, 12-1)·목차 패널(F-21, 12-2)·코드 블록 구문 색상(F-22, 12-3)을 구현했고, 뷰어 위 끌어다 놓기(10-6)·실행 중 제거 안내(9-7) 결함을 고쳤다. 화면·실행 확인이 남았다(브랜치 `feature/viewer-find`).

## 검토 항목 결정 결과 (2026-11-17, 모두 제안대로 확정)

다른 문서의 "(검토 항목 N)" 표기는 이 목록을 가리킨다. 괄호는 상세 내용이 있는 위치다.

1. **편집 모드의 탐색 패널** — 편집 모드로 바꾸면 트리(목록 창은 트리 통합으로 없어짐)를 자동으로 접어 편집기|미리보기에 폭을 몰아주고,
   `Ctrl+B`나 왼쪽 가장자리 버튼으로 다시 펼친다. (01 F-07)
2. **저장 방식** — 수동 저장(`Ctrl+S`)과 미저장 경고만 두고 자동 저장은 하지 않는다. (01 F-10)
3. **이미 창이 열려 있을 때 다시 실행** — 실행할 때마다 새 창을 연다(단일 인스턴스 아님). (01 F-01)
4. **줌 배율 기억** — 실행할 때는 항상 100%로 시작하고, 실행 중에는 파일을 바꿔도 배율을 유지한다. (01 F-06)
5. **대상 확장자** — `.md`, `.markdown` (대소문자 무시). (01 F-03)
6. **재귀 목록 제외 규칙** — 숨김·시스템 폴더, `.git`, `node_modules`를 건너뛰고 최대 5,000개까지 표시한다. (01 F-03)
   → 2026-11-17 트리 통합으로 재귀 목록이 없어져 해당 없음. 전체 검색(P2)을 만들 때 다시 쓴다.
7. **화면 배치** — 트리 | 목록 | 뷰어 3열. (03 §2.1)
   → 2026-11-17 사용자 결정으로 트리 | 뷰어 2열로 바꿈(md 파일을 트리에 합침). (03 §2.1·§2.3)
8. **외부 변경 자동 반영** — MVP는 `F5` 수동 새로고침만 두고, 파일 감시 자동 새로고침은 후속(P2)으로 둔다. (01 §8)
9. **테스트용 패키지** — xUnit 관련 패키지, 커버리지 수집기, E2E 자동화용 FlaUI 모두 승인. (02 §2)
10. **Windows 11 새 우클릭 메뉴** — MVP는 레지스트리 방식으로 등록해 "더 많은 옵션 표시" 안에 나오게 하고,
    새 메뉴 최상단 노출은 후속(P2)으로 둔다. (02 §8)
