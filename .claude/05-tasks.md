## 남은 작업 순서 (2026-11-22 기준)

실행 확인(앱을 띄우는 테스트)은 매번 사용자에게 먼저 묻는다.

1. **테마 결함 마무리** — 6-4 스크롤바는 트리에서 E2E·화면으로 확인했고 E2E 전체 회귀도 통과했다(2026-11-22, 36개). 편집기·도움말 목차의 스크롤바 화면 확인이 남았다.
2. **사람이 해야 하는 실행 확인** — 10-6 끌어다 놓기(PoC-7: 뷰어 위에 놓아도 열리는지), 6-2 실행 중 Windows 앱 모드 변경, 6-3 전환 시 번쩍임·스크롤 유지.
3. **탐색기 메뉴 실제 확인** — 9-2 등록·해제 레지스트리, 9-3 다른 폴더 exe("나중에" 뒤 다시 묻지 않음 포함), 9-4 탐색기 4곳, 9-5 아이콘, 9-6 설치 제거 시 해제.
4. **마무리** — 11-3 E2E 보강(시나리오 6·8·9, 즐겨찾기·트리 우클릭·자동 새로고침), 11-4 성능, 11-5 접근성, 11-6·11-7 배치 파일로 배포본 다시 만들기·깨끗한 PC·Windows 10 확인.
5. **후속 기능(Phase 12)** — 12-1 뷰어 안 찾기 → 12-2 목차 패널 → 12-3 코드 블록 구문 색상 → 12-4 단일 인스턴스(설정으로 선택). 각 기능은 01 요구사항 → 02·03 설계 → 테스트 → 구현 순서로 한다.

### E2E 시나리오

1. 폴더 아이콘 우클릭 → "MDFileViewer로 열기" → 트리에 그 폴더가 선택·펼쳐지고 그 폴더의 md 파일이 트리에 보인다.
2. 폴더 안 빈 공간 우클릭 → 실행 → 현재 폴더가 선택된다.
3. `.md` 파일 우클릭 → 실행 → 그 파일이 뷰어에 표시되고 트리에서 선택되어 있다.
4. 트리에서 폴더를 펼치면 하위 폴더 다음에 md 파일이 보이고, md 파일을 고르면 뷰어에 열리며, 행을 클릭해도 가로 스크롤이 움직이지 않는다. (처음 시나리오 "하위 폴더 포함 토글"은 2026-11-17 트리 통합으로 바꿈)
5. 줌 `+`·`−`·`100%`·`Ctrl+휠`이 01 F-06대로 동작한다.
6. 테마 3가지가 앱 UI·문서·편집기·도움말에 모두 적용된다.
7. `Ctrl+E` → 수정 → 미리보기 갱신 → `Ctrl+S` → 보기 모드에 수정 내용이 보인다.
8. 미저장 상태에서 탭 닫기·보기 전환·`F5`·창 닫기 → 확인 대화상자가 뜨고 `[취소]`면 아무것도 바뀌지 않는다. 다른 파일 선택·탭 전환은 묻지 않고 변경이 그 탭에 남는다(01 F-10·F-17, 2026-11-18 결정으로 바뀜).
9. `F1` → 도움말 창이 열리고, 목차를 고르면 해당 문법으로 이동한다.
10. 링크 샘플 문서에서 웹·앵커·다른 md·로컬 파일·없는 파일 링크가 01 F-05 표대로 동작한다.
